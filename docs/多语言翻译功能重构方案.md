# 多语言翻译功能重构方案

> 版本：v1.0  
> 日期：2026-08-13  
> 目标：支持海外上线，17 种语言完整覆盖，管理后台可切换语言

---

## 一、现有翻译功能漏洞审计

### 1.1 漏洞总览

| 编号 | 严重程度 | 漏洞描述 | 影响范围 |
|:---:|:---:|---|:---:|
| V1 | **严重** | 用户端 15 种非中文/非英语语言为"假翻译" | 用户端 streamI18n |
| V2 | **严重** | 后端异常消息硬编码中文，无国际化 | 全部 API 错误响应 |
| V3 | **严重** | 后端返回内容（分类名、剧名）仅有中文 | 内容展示 |
| V4 | **高** | 三套独立 i18n 实例，翻译键重复维护 | 全局 |
| V5 | **高** | 无语言自动检测，默认永远中文 | 用户体验 |
| V6 | **高** | 无翻译完整性校验，缺失键静默退化 | 翻译质量 |
| V7 | **中** | 无 RTL（阿拉伯语）布局支持 | 布局 |
| V8 | **中** | 翻译文件全量加载，无按需加载 | 性能 |
| V9 | **中** | 管理后台仅中文，海外运营人员无法使用 | 管理后台 |
| V10 | **低** | 无 A/B 测试/灰度发布能力 | 运营 |

---

### 1.2 漏洞详细分析

#### V1: 用户端 15 种语言"假翻译"（严重）

**文件**: `front/admin/src/locales/streamI18n.js` 第 1029-1053 行

```javascript
// 这是当前的问题代码模式：
export const messages = {
  'zh-CN': zhCN,           // 中文完整翻译 ~500+ 键
  'en-US': enUS,           // 英文完整翻译 ~500+ 键
  'ja-JP': clone(enUS, {   // 日语 = 英文 + 仅覆盖 nav 3 个键！
    language: { label: '言語', current: '日本語' },
    nav: { ...enUS.nav, home: 'ホーム', category: 'カテゴリ', ... }
  }),
  'ko-KR': clone(enUS, {   // 韩语 = 英文 + 仅覆盖 nav 3 个键
    language: { label: '언어', current: '한국어' },
    nav: { ...enUS.nav, home: '홈', category: '분류', ... }
  }),
  // ... 其他 13 种语言同样只有 nav 和 language 被覆盖
}
```

**问题本质**: 用户切换到日语/韩语/泰语/越南语/印尼语/马来语/西班牙语/法语/德语/葡萄牙语/俄语/意大利语/土耳其语/阿拉伯语/印地语/瑞典语时，**整个界面只有导航栏和语言标签显示对应语言，其余所有内容（剧集详情、按钮、提示、分类、错误消息等）全部显示英文**。

**验证方法**: 切换语言为"日本語"后，观察首页、分类页、详情页、个人中心 — 所有内容仍是英文。

#### V2: 后端异常消息硬编码中文（严重）

**文件**: `backed/server/src/main/java/com/duanju/config/ApiExceptionHandler.java`

```java
// 所有错误消息硬编码为中文，海外用户完全看不懂
private static final String GENERIC_ERROR_MESSAGE = "服务繁忙,请稍后重试";

@ExceptionHandler(DuplicateKeyException.class)
public R<Void> duplicate(DuplicateKeyException ex) {
    return R.fail("记录已存在,请勿重复操作");    // 中文
}

@ExceptionHandler(HttpMessageNotReadableException.class)
public R<Void> unreadable(HttpMessageNotReadableException ex) {
    return R.fail("请求参数格式错误,请检查数字、时间和必填项");  // 中文
}
```

**影响**：海外用户遇到任何错误都看到中文提示，完全无法理解。

#### V3: 后端返回内容仅有中文（严重）

分类名、短剧标题、短剧简介、标签等业务数据存储在数据库中，后端直接返回中文原文，没有任何翻译机制。

```
当前流程：
DB(中文) → API(中文) → 前端直接展示(中文)

期望流程：
DB(中文) → API(带 locale 参数) → 前端展示对应语言
```

#### V4: 三套独立 i18n 实例（高）

| 文件 | 大小 | 语言数 | 实例名 |
|------|:---:|:---:|:---:|
| `front/admin/src/locales/streamI18n.js` | ~40KB | 17 | `streamI18n` |
| `front/admin/src/i18n.js` | 231KB | 1 (仅中文) | `adminI18n` |
| `front/uniapp/utils/i18n.js` | 90KB | 17 | uni-app 内置 |

**重复键示例**（三个文件都存在）：

| 键 | streamI18n | uniapp | adminI18n |
|---|:---:|:---:|:---:|
| `appTitle` | "星幕短剧" | "短剧" | "短剧运营后台" |
| `all` | — | "全部" | — |
| `profile` | "个人中心" | "我的" | — |
| `save` | "保存修改" | "追剧" | "保存" |
| `loading` | "加载中" | "加载中" | — |
| `delete` | "删除" | "删除" | "删除" |
| `cancel` | "取消" | "取消" | — |

三套实例在 `main.js` 中同时注册，互不通信：

```javascript
createApp(App).use(ElementPlus).use(router).use(streamI18n).use(adminI18n).mount('#app')
```

#### V5: 无语言自动检测（高）

`currentLocale()` 函数永远返回 `'zh-CN'`：

```javascript
export function currentLocale() {
    // 管理后台固定使用中文，不支持切换
    return 'zh-CN'
}
```

没有：
- 浏览器语言检测 (`navigator.language`)
- 用户偏好持久化（localStorage 读取）
- 服务端 IP 地理位置推断

#### V6: 无翻译完整性校验（高）

当前没有任何机制检测：
- 某个语言缺少某个翻译键
- 翻译键在不同语言间不一致
- 翻译文本中包含未转义的 HTML 标签

`fallbackLocale: 'zh-CN'` 配置了但实际效果有限 — 因为 `clone(enUS)` 模式使得所有语言都有一个"完整"的英文副本，缺少的键不会触发 fallback 而是直接显示英文。

#### V7: 无 RTL 布局支持（中）

`languageOptions` 中阿拉伯语标记了 `dir: 'rtl'`，`applyLocaleSideEffects` 也设置了 `document.documentElement.dir = 'rtl'`，但：

- 没有任何 RTL 专属 CSS 样式
- 布局方向（flexbox、grid、padding/margin 方向）不会自动翻转
- 输入框文字方向不会自动调整

#### V8: 翻译文件全量加载（中）

- `streamI18n.js` 单文件 1090 行，包含全部 17 种语言
- `uniapp i18n.js` 单文件 90KB，包含全部 17 种语言
- 用户首次加载需要下载所有语言，即使只用一种

#### V9: 管理后台仅中文（中）

`adminI18n` 只包含 `zh-CN` 翻译，231KB 的单文件没有任何其他语言。海外运营人员无法使用管理后台。

#### V10: 无 A/B 测试/灰度发布能力（低）

无法在特定地区/用户群先测试新翻译，或逐步放量。

## 二、重构目标

| 目标 | 指标 |
|------|------|
| 17 种语言完整翻译覆盖率 | 100%（所有翻译键在所有语言中都有对应翻译） |
| 后端错误消息国际化 | 100%（所有 API 错误响应支持多语言） |
| 前端首屏翻译加载体积 | ≤ 20KB（仅当前语言） |
| 翻译切换响应时间 | < 100ms |

| 管理后台多语言 | 支持中/英/日/韩/西/法/德/葡/俄/阿/泰/越/印尼 |
| RTL 语言支持 | 阿拉伯语完整 RTL 布局 |

### 3.2 核心设计原则

1. **统一翻译键管理**：所有前端共享一套翻译键定义，后端使用独立的 `messages_*.properties`
2. **按需加载**：前端只加载当前语言 + 降级语言，不加载全部 17 种
3. **降级链**：`用户语言 → en-US → zh-CN`（后端同理）
4. **翻译键唯一性**：通过 `keys.json` 作为 schema，CI 自动校验所有语言文件
5. **前端侧翻译**：UI 文本由前端 vue-i18n 处理；后端仅返回错误码，前端映射到本地化消息
6. **内容翻译**：分类名、剧名等动态内容，后端存储多语言字段，按 `X-Locale` 返回

## 五、前端 i18n 重构方案

### 5.1 统一 i18n 实例

不再使用 `streamI18n` + `adminI18n` 双实例，改为单一 `appI18n` 实例，通过 namespace 区分：

```javascript
// front/admin/src/i18n/index.js
import { createI18n } from 'vue-i18n'
import { detectLocale, STORAGE_KEY, languageOptions } from './loader'

// 初始仅加载当前语言和降级语言
const initialLocale = detectLocale()

export const i18n = createI18n({
  legacy: false,
  globalInjection: true,
  locale: initialLocale,
  fallbackLocale: ['en-US', 'zh-CN'],  // 降级链
  messages: {},  // 空对象，由 loader 按需加载
  missingWarn: process.env.NODE_ENV === 'development',
  fallbackWarn: process.env.NODE_ENV === 'development'
```

```javascript
const loadedLocales = new Set()

/**
 * 语言检测优先级：
 * 1. localStorage 用户偏好
 * 2. 浏览器语言 (navigator.language)
 * 3. 默认 zh-CN
 */
export function detectLocale() {
  const stored = localStorage.getItem(STORAGE_KEY)
  if (stored && languageOptions.find(o => o.code === stored)) return stored

  const browser = navigator.language
  const exact = languageOptions.find(o => o.code === browser)
  if (exact) return exact.code

  const prefix = browser.split('-')[0]
  const fuzzy = languageOptions.find(o => o.code.startsWith(prefix))
  if (fuzzy) return fuzzy.code

  return DEFAULT_LOCALE
}

export function applyLocaleSideEffects(locale) {
  const option = languageOptions.find(o => o.code === locale) || languageOptions[0]
  document.documentElement.lang = option.code
  document.documentElement.dir = option.dir || 'ltr'
  localStorage.setItem(STORAGE_KEY, option.code)
}

export async function loadLocaleMessages(locale) {
  if (loadedLocales.has(locale)) return

  try {
    // 动态导入翻译文件
    const module = await import(`../../shared/i18n/${locale}.json`)
    i18n.global.setLocaleMessage(locale, module.default)
    loadedLocales.add(locale)
  } catch (err) {
    console.warn(`Failed to load locale: ${locale}, falling back to en-US`, err)
    if (!loadedLocales.has('en-US')) {
      await loadLocaleMessages('en-US')
    }
  }
}
```

### 6.3 重构 ApiExceptionHandler

```java
@RestControllerAdvice
public class ApiExceptionHandler {
    private static final Logger log = LoggerFactory.getLogger(ApiExceptionHandler.class);

    @Autowired
    private MessageSource messageSource;

    @ExceptionHandler(ForbiddenException.class)
    public R<Void> forbidden(ForbiddenException ex, Locale locale) {
        log.warn("Forbidden: {}", ex.getMessage());
        return R.forbidden(getMessage("error.forbidden", locale));
    }

    @ExceptionHandler(IllegalArgumentException.class)
    public R<Void> badRequest(IllegalArgumentException ex, Locale locale) {
        log.warn("Bad request: {}", ex.getMessage());
        return R.fail(getMessage("error.invalid_params", locale));
    }

    @ExceptionHandler(DuplicateKeyException.class)
    public R<Void> duplicate(DuplicateKeyException ex, Locale locale) {
        log.warn("Duplicate key: {}", ex.getMessage());
        return R.fail(getMessage("error.duplicate_record", locale));
    }

    @ExceptionHandler(Exception.class)
    public R<Void> fallback(Exception ex, Locale locale) {
        log.error("未处理的异常: {}: {}", ex.getClass().getName(), ex.getMessage(), ex);
        return R.fail(getMessage("error.server_busy", locale));
    }

    private String getMessage(String code, Locale locale) {
        try {
            return messageSource.getMessage(code, null, locale);
        } catch (Exception e) {
            return messageSource.getMessage(code, null, Locale.SIMPLIFIED_CHINESE);
        }
    }
}
```

## 七、内容翻译方案

### 7.1 问题分析

当前后端返回的短剧标题、分类名、简介等都是中文，需要支持多语言。有以下几种方案：

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| A: 数据库多语言字段 | 每个可翻译字段存多语言版本 | 准确、可控 | 数据库改动大 |
| B: 翻译表 | 独立翻译表存储所有翻译 | 灵活、可扩展 | 查询复杂度高 |
| C: 前端翻译映射 | 前端维护内容翻译映射表 | 简单、改动小 | 内容不可动态更新 |

### 7.2 推荐方案：B（翻译表）

**推荐方案**：使用独立的 `content_translation` 翻译表，适合动态内容：

```sql
CREATE TABLE content_translation (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    entity_type VARCHAR(50) NOT NULL COMMENT '实体类型: drama, category, category_option, drama_tag',
    entity_id BIGINT NOT NULL COMMENT '实体ID',
    field_name VARCHAR(50) NOT NULL COMMENT '字段名: title, synopsis, label',
    locale VARCHAR(10) NOT NULL COMMENT '语言代码: zh-CN, en-US, ja-JP...',
    content TEXT NOT NULL COMMENT '翻译内容',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_entity_field_locale (entity_type, entity_id, field_name, locale),
    INDEX idx_entity_type_id (entity_type, entity_id)
```

### 7.3 ContentTranslationService

```java
@Service
public class ContentTranslationService {

    @Autowired
    private ContentTranslationMapper mapper;

    private final LoadingCache<String, Map<String, String>> cache = CacheBuilder.newBuilder()
        .maximumSize(1000)
        .expireAfterWrite(30, TimeUnit.MINUTES)
        .build(new CacheLoader<>() {
            @Override
            public Map<String, String> load(String key) {
                String[] parts = key.split(":");
                return loadTranslations(parts[0], Long.parseLong(parts[1]));
            }
        });

    public String translate(String entityType, Long entityId, String fieldName, String locale) {
        if ("zh-CN".equals(locale)) return null; // 中文无需翻译
        String cacheKey = entityType + ":" + entityId;
        Map<String, String> translations = cache.getUnchecked(cacheKey);
        return translations.get(fieldName + ":" + locale);
    }

    private Map<String, String> loadTranslations(String entityType, Long entityId) {
        return mapper.selectByEntity(entityType, entityId)
            .stream()
            .collect(Collectors.toMap(
                t -> t.getFieldName() + ":" + t.getLocale(),
                ContentTranslation::getContent
            ));
    }
}
```

## 八、翻译质量保障

### 8.1 CI 翻译完整性校验

```javascript
// scripts/validate-i18n.js
// 运行方式: node scripts/validate-i18n.js
// 在 CI 中运行，翻译缺失时构建失败

import fs from 'fs'
import path from 'path'

const I18N_DIR = path.resolve('front/shared/i18n')
const keysSchema = JSON.parse(fs.readFileSync(path.join(I18N_DIR, 'keys.json'), 'utf-8'))
const locales = fs.readdirSync(I18N_DIR)
  .filter(f => f.endsWith('.json') && f !== 'keys.json')
  .map(f => f.replace('.json', ''))

const errors = []

// 1. 提取所有必需的翻译键
function extractKeys(schema, prefix = '') {
  const keys = []
  for (const [namespace, def] of Object.entries(schema.namespaces)) {
    for (const key of def.keys) {
      keys.push(`${namespace}.${key}`)
    }
  }
  return keys
}

const requiredKeys = extractKeys(keysSchema)

// 2. 检查每个语言文件
for (const locale of locales) {
  const filePath = path.join(I18N_DIR, `${locale}.json`)
  const data = JSON.parse(fs.readFileSync(filePath, 'utf-8'))

  for (const fullKey of requiredKeys) {
    const [namespace, ...rest] = fullKey.split('.')
    const key = rest.join('.')
    if (!data[namespace] || data[namespace][key] === undefined) {
      errors.push(`[${locale}] Missing: ${fullKey}`)
    }
  }

  // 3. 检查是否有未定义的键
  for (const [namespace, translations] of Object.entries(data)) {
    if (!keysSchema.namespaces[namespace]) {
      errors.push(`[${locale}] Unknown namespace: ${namespace}`)
      continue
    }
    for (const key of Object.keys(translations)) {
      const validKeys = keysSchema.namespaces[namespace].keys
      if (!validKeys.includes(key)) {
        errors.push(`[${locale}] Unknown key: ${namespace}.${key}`)
      }
    }
  }
}

// 4. 检查参数占位符一致性
for (const locale of locales) {
  const filePath = path.join(I18N_DIR, `${locale}.json`)
  const data = JSON.parse(fs.readFileSync(filePath, 'utf-8'))

  for (const fullKey of requiredKeys) {
    const [namespace, ...rest] = fullKey.split('.')
    const key = rest.join('.')

    // 检查 zh-CN 中的占位符
    const zhCNFile = JSON.parse(fs.readFileSync(path.join(I18N_DIR, 'zh-CN.json'), 'utf-8'))
    const zhCNValue = zhCNFile[namespace]?.[key]
    const value = data[namespace]?.[key]

    if (zhCNValue && value) {
      const zhCNPlaceholders = (zhCNValue.match(/\{[^}]+\}/g) || []).sort()
      const placeholders = (value.match(/\{[^}]+\}/g) || []).sort()
      if (JSON.stringify(zhCNPlaceholders) !== JSON.stringify(placeholders)) {
        errors.push(`[${locale}] Placeholder mismatch: ${fullKey} (expected ${zhCNPlaceholders}, got ${placeholders})`)
      }
    }
  }
}

if (errors.length > 0) {
  console.error('❌ Translation validation failed:')
  errors.forEach(e => console.error(`  ${e}`))
  process.exit(1)
} else {
  console.log('✅ All translations validated successfully')
}
```

### 8.2 翻译复用建议

对于翻译不完整的情况，提供翻译覆盖率报告：

```javascript
// scripts/i18n-coverage.js
// 输出各语言的翻译覆盖率

for (const locale of locales) {
  const filePath = path.join(I18N_DIR, `${locale}.json`)

    total++
    if (data[namespace]?.[key]) filled++
  }

}
```

### 10.1 翻译文件按需加载

| 优化前 | 优化后 |
|--------|--------|
| 加载全部 17 种语言 (~200KB) | 仅加载当前语言 + en-US 降级 (~30KB) |
| 同步加载 | 异步动态 import |
| 单文件打包 | 按语言分包 |

### 10.2 翻译缓存策略

```javascript
// 已加载的语言缓存到内存
const loadedLocales = new Set()

// 同时存储到 localStorage 作为二次缓存
export function cacheLocaleToStorage(locale, messages) {
  try {
    localStorage.setItem(`i18n_cache_${locale}`, JSON.stringify(messages))
    localStorage.setItem('i18n_cache_version', I18N_VERSION)
  } catch (e) {
    // localStorage 满了，降级到纯内存缓存
  }
}
```

### 10.3 后端翻译缓存

```java
// MessageSource 已内置缓存，配置 cacheSeconds 即可
ms.setCacheSeconds(3600);  // 1小时缓存

// 内容翻译使用 Guava LoadingCache
private final LoadingCache<String, Map<String, String>> cache = CacheBuilder.newBuilder()
    .maximumSize(1000)
    .expireAfterWrite(30, TimeUnit.MINUTES)
    .build(...);
```

## 十三、翻译资源获取建议

### 13.1 翻译方法优先级

1. **专业人工翻译**（推荐用于核心 UI）
   - 翻译质量最高，翻译费用约 $0.05-0.15/词
   - 建议外包给专业翻译公司（如 Gengo、OneSky）
   
2. **AI 翻译 + 人工校对**（推荐用于内容翻译）
   - 使用 DeepL/Google Translate API 批量翻译
   - 再由母语者校对修正
   - 成本降低 60-80%

3. **社区翻译**（长期运营）
   - 建立翻译贡献平台
   - 用户可提交翻译建议
   - 管理员审核后上线

### 13.2 翻译管理平台

建议使用翻译管理平台（TMS）集中管理：

| 平台 | 特点 | 价格 |
|------|------|------|
| Lokalise | 全功能，CI/CD 集成 | $120/月起 |
| Crowdin | 开源项目免费 | 免费/付费 |
| POEditor | 性价比高 | $19/月起 |
| Weblate | 自托管，开源 | 免费 |

## 十四、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|------|
| 翻译质量不达标 | 用户体验差 | 分阶段翻译，核心 UI 人工翻译，次要内容 AI+人工校对 |
| 翻译遗漏导致显示异常 | 空白/乱码 | CI 自动校验 + 降级链兜底 |
| 内容翻译数据量大 | 数据库膨胀 | 只翻译必要字段，大文本使用 AI 翻译 |
| 翻译切换后页面闪烁 | 体验差 | 使用 `<Suspense>` + loading 过渡 |
| 非拉丁字符（泰文、阿拉伯文）排版问题 | 布局错乱 | 使用 CSS 逻辑属性，测试覆盖所有语言 |
| 第三方库（Element Plus）不完整支持 | 部分英文 | 配置 Element Plus 国际化 |
